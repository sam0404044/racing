# 霓虹大獎賽週末（4 賽段聯賽 demo）

《極速駕駛-最終指令》比賽層的聯賽框架版本：
**① 自由練習（可跳）→ ② 排位賽 → ③ 衝刺賽 → ④ 正賽（NCC-7 空降）**，
同一批人類車手貫穿全週末、結轉鏈為「排位→起跑格、衝刺→buff＋獎勵牌、正賽→總結算」。

## 怎麼跑
靜態網頁、無 build。在本資料夾起任一靜態伺服器後開 `index.html`：
```
python3 -m http.server 8080      # 或 npx serve
# 瀏覽 http://localhost:8080/
```
（直接 file:// 開會因 ES module CORS 失敗、必須走 http。）

## 檔案結構
| 檔案 | 角色 |
|---|---|
| `index.html` | 入口：引擎 root（canvas）＋ shell root（DOM） |
| `run.js` ★新 | 週末編排器：賽段狀態機、跨段牌庫、buff 兌換、總結畫面 |
| `quali.js` ★新 | 排位賽：累積速度淘汰制（DOM 輕量賽制、與引擎獨立） |
| `game.js` | 比賽引擎（原第二關）＋ 新增 Session 層（見下） |
| `config.js` | 原資料 ＋ 新增：pack 車手 D1–D4、週末名單、排位卡池、衝刺兌換 |
| `neon-shell.css` ★新 | shell 與排位賽樣式（陽春、沿用品牌深色） |
| `state.js` / `canvas-viewport.js` / `chassis-hud.js` / `progress.js` / `final-driver.css` | 原樣沿用 |

## game.js 動了什麼（Session 層）
- 新增 `startSessionRace(cfg)` / `cfg.onComplete(result)`：引擎吃 config 進、吐結果出。
  `cfg = { id, name, lineup, tutorial, maxRounds, allowQuit, deckPermanent, startRank, rankTotal, buffs, isMainRace, completeLabel, onComplete }`
  `result = { sessionId, skipped, rank, rankTotal, rounds, deckPermanent }`
- `initStage2State` 參數化：對手隊列、教學旗標、回合上限、永久牌庫注入、非教學直接洗正常賽段池。
- `loadStage` 支援起跑格覆寫（startRank / rankTotal）。
- 進場 buff 全部復用既有效果：暖胎=keepSpeed、情報=showOpponent、氣勢=穩定區每回合地板 1 格。
- 練習模式畫面左上角常駐「結束練習」按鈕；終局畫面在 session 模式改為「完成賽段 ➜」回報結果。
- 不再寫 `markLevelCleared`（聯賽結果由 run.js 接走）。

## 經營層掛載點（之後接）
- 賽段之間的 shell 畫面（run.js 各 `show*Intro`）＝ 備賽期決策插入點。
- 週末總結畫面（`showSummary`）＝ 經營結算插入點（名次/積分 → KPI/資金/士氣）。
- 引擎完全不需再動：經營層只讀 `result`、只改 `cfg`。

## 已知狀態 / 待調

## 輪胎機制（第三關移植、v2）

### 核心
- 每場賽段 5 格輪胎；左下部件 HUD 的輪胎隨胎量變色：綠 → 黃綠 → 黃 → 橘 → 紅（≤25% 危急脈動＋「⚠ 輪胎危急」警示）。
- 輪胎歸 0 → 本賽段報銷：聯賽模式按鈕變「完成賽段（DNF）➜」、單段模式為「再試一次」。

### 消耗來源
| 來源 | 消耗 |
|---|---|
| 「氮氣噴射」「換道節奏」打出 | -1 胎（取代原本的棄牌效果） |
| 超車 QTE 失敗（<60% 滿分） | -1 胎 |
| 彎道 QTE 失敗 | -1 胎 ＋ 1 失誤牌 |
| 甩尾過彎 QTE 失敗 | -1 胎（速度懲罰照舊） |
| c7 坑洞段踩坑 | -1 胎（對手踩坑 → 速度/2） |
| c6 油污段 QTE 失敗 | -1 胎 ＋ 失誤牌 ＋ 滑到隨機鄰道 |
| 「暖胎電熱絲」裝備啟動 | -1 胎 |

### 新賽段（進一般賽段池、共 7 段）
- **c7 坑洞段**：三道 +5，隨機抽 1 安全道、其餘藏坑（可見、賽段內每動重抽位置）。
- **c6 油污段**：油污道 +10 但踏入強制彎道 QTE、難度 +1 級、失敗滑開；位置每次重抽。
- 對手 AI 會避坑避油污（清道夫光環免疫災害並保護同道玩家）。

### 新車隊牌（獎勵池）
- **補丁**：撞坑時不扣胎不降速（一次性）。
- **保胎策略**：所有指令牌 -10 速度；免疫每回合第 1 次輪胎消耗。

### 聯賽結轉
- 練習：滿胎、不結轉。衝刺賽：全新 5 胎。
- 正賽起跑胎 = min(5, 衝刺剩餘 + 2)（「賽間快速補胎」）；桿位跳過衝刺 → 滿胎。
- 衝刺賽爆胎 = 視為墊底（空手進正賽）；正賽爆胎 = 週末以 DNF 收場。

### 刻意不移植（口徑差異）
- **甩尾過彎數值**：維持聯賽版（成功 +30 / 失敗 -20）。第三關的甩尾其實是 TODO 樁（程式註明「當成普通 +0 牌處理」），聯賽版結算反而完整；僅補上失敗扣胎。
- **初始牌庫**：維持聯賽版固定順序（教學依賴寫死的第一手），不採第三關含「換道節奏」的 8 張版。
- **衝刺 buff「暖胎完成」不耗胎**：它是兌換獎勵、非賽中裝備選取；賽中三選一拿到的「暖胎電熱絲」才有啟動 -1 胎。
